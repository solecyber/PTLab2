# Лабораторная работа 2 по технологиям программирования

[![Django CI](https://github.com/solecyber/PTLab2/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/solecyber/PTLab2/actions/workflows/ci.yml)

## Задание

**Вариант 10. Магазин одежды.** При одновременной покупке товаров двух и более
видов покупатель получает скидку **10% на всю сумму**. Два разных товара одного
вида, например две модели футболок, не дают скидку.

В каталоге «Крой» можно добавлять одежду в корзину, менять количество, удалять
позиции и оформлять учебные заказы. Например, футболка за 1 490 ₽ и рубашка за
3 490 ₽ стоят вместе 4 980 ₽. Скидка составляет 498 ₽, к оплате 4 482 ₽.

## Как устроен проект

| Часть MVC | Реализация в Django |
| --- | --- |
| Модель | `shop/models.py`. Хранит товары, покупки и позиции заказов. |
| Представление | `shop/templates/shop/`. HTML-шаблоны каталога, корзины и подтверждения. |
| Контроллер | `shop/urls.py` и `shop/views.py`. Маршруты вызывают обработчики запросов. |

Django называет такой подход MVT. Обработчик выбирает шаблон и передаёт ему
данные, а маршрутизатор определяет обработчик по URL. Расчёт вынесен в
`shop/cart.py`. При оформлении сервер повторно рассчитывает суммы по данным
из базы и сохраняет заказ и его позиции в одной транзакции. Миграция
`0003_catalog` загружает шесть демонстрационных товаров.

## Запуск

Нужен Python 3.13. Для локального запуска используется SQLite. При передаче
`DATABASE_URL` приложение подключается к PostgreSQL.

```bash
git clone https://github.com/solecyber/PTLab2.git
cd PTLab2
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте [каталог](http://127.0.0.1:8000/). Для оформления учебного заказа
введите вымышленные имя и адрес. Для запуска тестов выполните
`python manage.py test`. Тесты покрывают скидку, изменение корзины, защиту
форм и сохранение заказа.

## CI и развёртывание

Ветка `feature/clothing-discount` содержит реализацию варианта. GitHub Actions
поднимает PostgreSQL, проверяет миграции, запускает тесты и измеряет покрытие.

Для развёртывания подключите репозиторий в Render через **New → Blueprint**.
В `render.yaml` указаны бесплатный веб-сервис, сборка статики, миграции при
запуске и проверка `/healthz/`. Render автоматически создаёт секретный ключ.
Последующие развёртывания выполняются после успешных проверок коммита в
`main`. [Документация Render](https://render.com/docs/deploys#integrating-with-ci)

Бесплатный демонстрационный сервис использует SQLite, поэтому корзины и заказы
могут сбрасываться при перезапуске. Каталог восстанавливается миграцией.
Для постоянного хранения можно указать PostgreSQL через `DATABASE_URL`.
